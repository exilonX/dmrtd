Data: 7C 00 (empty dynamic authentication data)

7C [LEN] 80 [LEN] [ENCRYPTED_NONCE]

s = Decrypt(K_π, encrypted_nonce)

Mapping - Generate Ephemeral Domain Parameters

PCD
→
PICC
PCD
←
PICC
SEND RECEIVE ECDH MAPPING
Command APDU:
7C [LEN] 81 [LEN] [PCD_MAPPING_PUBLIC_KEY]
where PCD_MAPPING_PUBLIC_KEY = 04 || X || Y (65 bytes)
Response APDU:
7C [LEN] 82 [LEN] [PICC_MAPPING_PUBLIC_KEY]
Generic Mapping (GM) Operations:
1. Generate random mapping key pair: (d_map, Q_map)
2. Exchange Q_map with PICC → get Q_map_PICC
3. H = ECDH(d_map, Q_map_PICC) = d_map × Q_map_PICC
4. G' = s × G + H (new ephemeral generator)
5. Ephemeral domain params: (p, a, b, G', n, h)
3

Key Agreement - Exchange Ephemeral Public Keys

PCD
→
PICC
PCD
←
PICC
SEND RECEIVE ECDH KDF
Command APDU:
7C [LEN] 83 [LEN] [PCD_EPHEMERAL_PUBLIC_KEY]
Generated using ephemeral domain parameters G'
Response APDU:
7C [LEN] 84 [LEN] [PICC_EPHEMERAL_PUBLIC_KEY]
Key Agreement & Derivation:
1. Generate ephemeral key pair using G': (d~, Q~)
2. Exchange Q~ with PICC → get Q~_PICC
3. K = ECDH(d~, Q~_PICC) = d~ × Q~_PICC
4. K_enc = KDF(K.x, "ENC", AES-256)
5. K_mac = KDF(K.x, "MAC", AES-256)
4

Mutual Authentication - Exchange Authentication Tokens

PCD
→
PICC
PCD
←
PICC
SEND RECEIVE CMAC VERIFY
Command APDU:
7C [LEN] 85 08 [AUTH_TOKEN_PCD]
where AUTH_TOKEN_PCD = first 8 bytes of CMAC(K_mac, T-Block_PICC)
Response APDU:
7C [LEN] 86 08 [AUTH_TOKEN_PICC]
where AUTH_TOKEN_PICC = first 8 bytes of CMAC(K_mac, T-Block_PCD)
T-Block Structure (Public Key Data Object):
T-Block = 7F49 [LEN] 06 0A [OID] 86 41 [PUBLIC_KEY]
• Tag 7F49: Public Key Data Object
• Tag 06: Object Identifier (OID)
• Tag 86: Ephemeral Public Key (65 bytes with 04 prefix)
Auth Token = CMAC(K_mac, T-Block)[0:8]
Mutual Verification:
1. PCD computes and sends: CMAC(K_mac, T-Block containing PICC's ephemeral public key)
2. PICC verifies PCD's token and responds with: CMAC(K_mac, T-Block containing PCD's ephemeral public key)
3. PCD verifies PICC's token
